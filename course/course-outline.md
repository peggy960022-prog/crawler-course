# 《網路偵探見習生》完整大綱（定案版）

**起點：** 學員會定義函式（Python 只到這個程度，前端只懂「區塊」）
**終點：** 能獨立爬靜態與動態網頁，並且知道「換一個網站時，該改腳本的哪個部分」
**執行環境：** Windows，使用 Antigravity 編輯器寫腳本
**故事主線：** 學員是「資料小鎮」的見習偵探，從只會敲門，到能找暗門、派機器人，最後獨立完成任務。

---

## 每章固定結構

**第 2～8 章：**
故事開場 → 一個小概念 → **詳細中文註解版範例** → **引導改參數（一次只改一個）** → 小練習 → **章末整理 + 更新 progress.md**

**第 0、1 章：**
故事開場 → 一個小概念 → 小練習 → 章末整理 + 更新 progress.md（這兩章幾乎沒有爬蟲腳本可改）

**範例腳本規則：**
- 腳本最上方有「設定區」，集中放網址、要抓的標籤或 class、頁數、輸出檔名，並以註解標示「換網站時改這裡」。
- 每次只改一個參數，執行後比較結果，說明改了哪裡、結果有何不同。

## 🎒 第一部：出發準備

### 第 0 章｜領裝備
- 故事：偵探先領工具箱，裡面都是別人做好的工具。
- 內容：`pip install`、`import`、使用別人寫好的函式、看說明文件
- Windows 環境確認：Python 是否已安裝與版本、Antigravity 終端機類型、工作資料夾、在哪個資料夾執行腳本、虛擬環境
- 銜接已會的內容：以前是「定義」函式，現在學「使用」別人的函式

### 第 1 章｜看懂盒子（前端只學剛好夠用）
- 1-1 網頁是一排排盒子（從已懂的「區塊」`div` 出發）
- 1-2 只認 5 種標籤：`div`、`p`、`a`、`h1`、`ul/li`
- 1-3 盒子的名牌：`class` 和 `id`
- F12 只教一個動作：用小箭頭點網頁，找到對應的原始碼
- 每一節都用 F12 實際對照網頁，不先背語法

## 🚪 第二部：靜態網頁

### 第 2 章｜敲門
- 內容：`requests.get()`、狀態碼（200、404）、`headers`
- 換網站要改：**網址、headers**

### 第 3 章｜拆信
- 內容：BeautifulSoup 只教 3 種找法（用標籤、`class`、`id` 找），取出文字與連結
- 新增概念：**盒子裡找盒子**（先找出每一筆資料的外層盒子，再用迴圈在裡面找標題、價格等）
- 練習：抓取清單型資料（如新聞標題清單）
- 換網站要改：**要抓的標籤、class、id（選擇器）**

### 第 4 章｜整理戰利品
- 內容：用 list、dict 整理資料，存成 CSV 和 JSON
- 重點：把前面步驟包成自己的函式，設定區的值變成函式的參數（用到已會的函式概念）
- Windows 注意：用相對路徑存檔；CSV 用 Excel 開啟時中文可能亂碼，課堂中實際測試後再教處理方式
- 換網站要改：**欄位名稱、輸出檔名**

### 第 5 章｜跑遍小鎮
- 內容：迴圈翻頁、`time.sleep`、`try/except`、`robots.txt` 與爬蟲禮儀
- 換網站要改：**頁數、休息秒數**
- 爬真實網站前，一律先確認 `robots.txt` 與使用條款，並控制請求頻率

## 🕳️ 第三部：動態網頁

### 第 6 章｜為什麼有些資料抓不到？
- 內容：有些內容是「後來才補進來的」；靜態與動態的差別；不談 JavaScript 怎麼寫

### 第 7 章｜找暗門
- 內容：F12 Network 只學一個篩選（Fetch/XHR）、找出 JSON、用 `requests` 直接拿資料
- JSON 對照已學過的 dict
- 這是動態網頁的主要解法
- 換網站要改：**API 網址、參數**

### 第 8 章｜派機器人進場（必修・精簡版）
- 工具：Playwright
- 內容：只教四個動作——開網頁、等、點、抓
- 為什麼必修：第 7 章只適用於有公開 JSON 的網站，有些網站沒有，或需要登入，這時要靠瀏覽器自動化
- Playwright 的安裝與瀏覽器下載方式，以官方文件為準，開課時確認
- 換網站要改：**等待條件、要點擊的目標**
